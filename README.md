# lvgl-micropython has moved

lvgl-micropython is now part of [omnipython-lvgl](https://github.com/PyDevices/omnipython-lvgl),
which generates the LVGL bindings and builds them for MicroPython,
CircuitPython and CPython from one tree. What was here lives in
`ports/micropython/`.

Build from there, and open issues there. This repository is archived and
keeps its history and releases for reference.
