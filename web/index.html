PyDevices / lv_micropython_cmod

MicroPython user C module glue for LVGL

lv_micropython_cmod is the MicroPython user C module glue that loads the LVGL binding generated by lv_bindings. It owns allocator integration, usermod registration, and the fixtures that prove import lvgl works on the unix (and related) ports you care about.

Clone it beside MicroPython and lv_bindings (or use the cmods workspace), regenerate the MicroPython binding when LVGL moves, then build the port with this module enabled. It is the firmware-side half of "LVGL on MicroPython" in the PyDevices stack — not the generator itself.

Build with lv_bindings + cmods

git clone https://github.com/PyDevices/lv_bindings.git
cd lv_bindings && git submodule update --init lvgl && cd ..
./lv_bindings/regenerate_lvmp.sh

git clone https://github.com/PyDevices/lv_micropython_cmod.git
# Build via cmods/build_mp.sh, or see this repo's own Make/CMake docs.
